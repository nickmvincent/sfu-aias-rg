# AI and Society Reading Group Website

This is the website for the AI and Society Reading Group at Simon Fraser University.

## Development

To run the site locally:

1. Install dependencies: \`bun install\`
2. Start development server: \`bun start\`
3. Visit http://localhost:8080

## Adding/Updating Events

1. Edit \`src/_data/events.json\` to add or modify events
2. Commit and push your changes
3. The site will automatically rebuild and deploy

## Contributing
